# Candy Magic Royale – Candy Artwork

This folder contains the uploaded transparent PNG candy illustrations used by the game board. The game currently uses the six non-empty PNG assets listed in `game.js`. PNG artwork is displayed as a front-facing candy illustration, while a native Babylon.js 3D candy remains as an automatic fallback if an image fails to load. These PNG files are 2D artwork, not editable 3D model files.
